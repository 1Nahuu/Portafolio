## 1. Descripción

Sitio web personal que presenta mi perfil profesional, habilidades técnicas, proyectos y formación académica.

## 3. Cómo ejecutarlo

1. Clonar el repositorio o descargar sus archivos.
2. Abrir el archivo `index.html` con doble clic.
3. El sitio se ejecutará directamente en cualquier navegador moderno.

No requiere servidor local, instalación de dependencias ni compilación.

Las tipografías se cargan desde Google Fonts. Si no hay conexión a Internet, el navegador utiliza fuentes del sistema como alternativa.

## 6. Detalles de implementación

- **HTML semántico:** utilización de etiquetas como `nav`, `section`, `article` y `footer`, con jerarquía de encabezados y textos alternativos en imágenes.
- **Accesibilidad:** contraste AA, estados de foco visibles y navegación por teclado en enlaces y botones.
- **Animaciones:** introducción estilo terminal, revelados al hacer scroll y microinteracciones. Se respeta la preferencia `prefers-reduced-motion`.
- **Independencia de JavaScript:** el contenido principal permanece visible aunque el script no se cargue.
- **Diseño responsive:** grillas fluidas y adaptación a diferentes tamaños de pantalla, desde 320 px, sin desbordamiento horizontal.
- **Sin dependencias ni build:** no utiliza frameworks, módulos ES, solicitudes `fetch` locales ni backend.
- **Diseño visual:** paleta exclusivamente oscura con acentos verdes.
