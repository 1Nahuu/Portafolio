proyecto 1 · 2026

BarberTrend AI - Sistema para Barbería

Desarrollé un sistema web de reservas online para una barbería masculina real: un sitio público responsive con servicios, precios, galería, horarios y contacto, más un motor de turnos que consulta la disponibilidad real y registra las reservas contra una API REST. El backend, en Java y Spring Boot, valida los datos en el servidor y previene turnos duplicados mediante clave compuesta. Incluye un panel administrativo privado con login para confirmar, completar y cancelar turnos y cerrar días o franjas horarias, además de seguridad con Spring Security, migraciones con Flyway, notificaciones por email y enlaces de WhatsApp con el mensaje de confirmación prearmado.

Segunda etapa: un asistente de marketing con IA, planificado pero todavía no implementado.

Java Spring Boot Spring Security REST API PostgreSQL H2 Flyway HTML/CSS JavaScript GitHub Actions
